# 更新日志

## [0.2.0] - 2026-04-01

### 新增功能 🎉

#### Web 应用界面
- ✨ 全新的 Web 界面 (`web_app.py`)
  - 可视化登录表单，无需配置环境变量
  - 卡片式书签浏览，支持缩略图预览
  - 多选/全选下载功能
  - 实时下载进度显示
  - 响应式设计，支持移动端

#### 命令行增强
- 🚀 新增 `serve-web` 命令启动 Web 应用
- 📝 改进配置管理，Web 模式下可选环境变量

#### 文档完善
- 📚 新增 `USAGE_GUIDE.md` 详细使用指南
- 📖 新增 `FEATURES.md` 功能特性说明
- 🔧 新增 `.env.example` 配置模板
- 🚀 新增 `start_web.sh` 一键启动脚本

### 改进优化 ⚡

#### 用户体验
- 💡 简化启动流程，一键启动 Web 应用
- 🎨 美化界面设计，采用 Twitter 配色方案
- 📊 实时状态反馈，清晰的成功/失败提示

#### 技术架构
- 🔄 采用 FastAPI 异步架构
- 🎭 使用 Playwright 异步 API
- 📦 后台任务处理下载队列
- 💾 自动保存登录状态

### 功能对比

| 功能 | 命令行模式 | Web 界面 |
|------|-----------|---------|
| 登录方式 | 环境变量 | 表单输入 ✨ |
| 书签浏览 | 自动全部 | 可视化选择 ✨ |
| 下载控制 | 批量下载 | 选择性下载 ✨ |
| 进度显示 | 终端输出 | 实时进度条 ✨ |
| 适用场景 | 自动化 | 交互式 ✨ |

### 使用建议

**推荐使用 Web 界面**，如果你：
- 想要可视化操作
- 需要选择性下载
- 不熟悉命令行

**推荐使用命令行**，如果你：
- 需要自动化批量下载
- 集成到其他脚本
- 服务器后台运行
