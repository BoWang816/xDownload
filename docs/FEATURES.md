# 功能特性

## 🌐 Web 界面（新增）

### 主要功能
- **可视化登录**：无需配置环境变量，直接在网页输入账号密码
- **书签浏览**：卡片式展示所有书签，包含缩略图、作者、文本预览
- **智能筛选**：自动识别包含视频或图片的推文
- **批量选择**：支持单选、多选、全选操作
- **实时下载**：后台异步下载，前端实时显示进度
- **状态提示**：清晰的成功/失败/进行中状态提示

### 技术特点
- 基于 FastAPI + Playwright 异步架构
- 单页应用，无需额外前端框架
- 响应式设计，支持桌面和移动端
- 自动保存登录状态，下次免登录

### 使用场景
- 个人使用：快速浏览和下载喜欢的视频
- 批量归档：选择性保存重要内容
- 内容管理：可视化管理书签内容

## 📋 命令行模式

### 自动化下载
- 无人值守批量下载
- 支持定时任务集成
- 监控模式持续运行

### 高级配置
- 灵活的参数配置
- 环境变量支持
- 脚本化集成

## 📊 仪表盘

### 监控功能
- 查看下载历史
- 配置信息展示
- API 接口支持

## 🔧 核心能力

### 登录管理
- 自动登录 Twitter/X
- 状态持久化
- 支持邮箱验证

### 内容抓取
- 智能滚动加载
- 去重处理
- 限制数量控制

### 下载功能
- 基于 yt-dlp 的可靠下载
- 自动重试机制
- 历史记录管理
- 断点续传支持

### 部署方式
- Docker 容器化
- 本地直接运行
- 云服务器部署

## 🎯 使用建议

### 推荐使用 Web 界面，如果：
- 需要可视化操作
- 想要选择性下载
- 不熟悉命令行

### 推荐使用命令行，如果：
- 需要自动化批量下载
- 集成到其他脚本
- 服务器后台运行

### 推荐使用仪表盘，如果：
- 需要查看历史记录
- 监控下载状态
- API 数据集成
